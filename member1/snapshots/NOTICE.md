# Snapshot source

These package metadata and JavaScript entrypoints were extracted without modification from the original, iter3 and iter5 ZIP archives in:

https://huggingface.co/datasets/anonymous2233/evol-servers/tree/162e3ffbea1717ac8a20fe9b26465e29117229e4

The selected package names, authors and MIT licensing declarations are retained in each package.json. Runtime dependencies are installed using the root package-lock.json. Provenance and file hashes are recorded in provenance.json.

Only the files required to start the selected services are included. Windows import-path compatibility is implemented in member1/windows_paths.mjs outside these snapshots.
